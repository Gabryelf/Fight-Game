## Особенности реализации:


Профессиональная архитектура: Чёткое разделение на ядро (GameEngine, AssetManager, InputManager, Camera), сущности (Fighter, CharacterData, EffectManager) и UI компоненты.

ООП с наследованием и композицией: Все классы следуют принципам SOLID, легко расширяются.

Система загрузки ассетов: Полная предзагрузка всех спрайтов с прогресс-баром и fallback-цветами при недоступности изображений.

Динамическая камера: Автоматическое изменение зума при расхождении персонажей, параллакс-фон с несколькими слоями.

Полная боевая система: Нормальные и специальные атаки с кулдаунами, хитбоксы, отбрасывание, расчёт защиты.

Управление состояниями: Меню, выбор персонажа, бой, пауза, экран победы с полной навигацией.

Визуальные эффекты: Вспышки при ударах, парящие цифры урона, анимации персонажей.

Расширяемость: Для добавления нового персонажа достаточно добавить запись в charactersConfig.js и загрузить спрайты.
